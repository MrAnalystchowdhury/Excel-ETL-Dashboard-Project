📊 Excel ETL & Dashboard Project

Trends in Reproductive, Maternal & Child Health of Bangladesh (1994–2022)


🔍 Project Overview

This project demonstrates how Microsoft Excel can be used as a lightweight, live ETL and reporting tool. I built a web-connected, refreshable data pipeline using Power Query to extract public health indicators directly from the DHS (Demographic and Health Surveys) QuickStats Bangladesh website and transformed the data into structured analytical dashboards covering long-term health trends in Bangladesh from 1994 to 2022 .

The project focuses on clean data modeling, reproducible analysis, and decision-ready reporting, similar to workflows used in development organizations, research teams, and M&E units.


🌍 Data Source
DHS QuickStats – Bangladesh (National level)
Public, authoritative health indicators
Covers multiple survey waves (1994–2022)


🔄 ETL Process (Excel + Power Query)

Extract ->
Used Power Query (Web connector) to pull data directly from the DHS QuickStats download URL. Designed for live refresh without manual data entry.

Transform ->
Removed all unnecessary fields
Retained only - Indicator, Value & SurveyYear
Standardized indicator names
Categorized each indicator into analytical domains - Child Health & Nutrition, Family Planning, Fertility, Mortality, Women’s Wellbeing & Empowerment & Health Facility

Load ->
Loaded cleaned data into Excel
Built pivot tables for year-wise and category-wise analysis
